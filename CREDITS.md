# Créditos

Este projeto foi iniciado a partir do arquivo `dental-website-template-main.zip` fornecido para esta tarefa. O README incluído no arquivo atribui o modelo original a Themedown e declara uso sob MIT; o ZIP não continha o arquivo `LICENSE`. Consulte a licença e a origem do modelo antes de redistribuir ou reutilizar os ativos originais.

## Pacote visual AS Dental V2

O pacote `AS_Dental_Pacote_Assets_V2` fornecido para esta tarefa foi integrado em `images/asdental-v2/`, incluindo derivados otimizados e originais. O manifesto descreve as gerações e dimensões. A marca é uma proposta visual e as imagens de pessoas e ambientes são ilustrativas e geradas por IA; confirmar aprovação e direitos de uso antes da publicação definitiva.
